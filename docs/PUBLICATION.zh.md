# 公开范围与脱敏

本仓库是新的独立Git历史，不继承开发电脑原仓库的提交、身份或旧备份。

保留：自己的增量补丁、通用主机测试、固定上游链接/提交、参数示例、进度与验收标准。上游依赖不复制进本项目，版权通知不是依赖实现的副本。

不包含：Apple镜像/缓存/信任数据/框架、固件FD/FAT/boot候选、编译器/SDK、分区表和备份、本地GPT/资源清单/marker字节数组、本地设备序列号或独有分区标识、照片/录像/二维码载荷/原始日志、个人工作目录、账号凭据，以及历史TWRP/分区调整工具。

源代码中用于匹配公开Apple程序版本的Mach-O UUID、通用UEFI协议GUID与寄存器常量不等于设备序列号；这些实现常量保持，不能盲目替换导致诊断改变。测试地址、PID和二维码session是合成fixture。

统一补丁会保留被删除的公开上游上下文，包括固定board版本已有的卷匹配UUID、manifest哈希及存储几何。它们逐字来自该公开版本，不是本次本地设备的GPT或新增运行记录；保留这些删除行才能在固定来源准确重放。不能据此向任意手机分区套用地址或身份。

公开版本使用中性Git作者；未配置远端，未上传。本地开发原件没有被改写或删除。

SHA清单用于核对公开文件字节。它不能替代安全审计或实机验收；新增文件也需重新检查，不能因为 `.gitignore` 存在就认为内容已脱敏。
